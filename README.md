# Server Performance Stats Tool

A lightweight, bash-based utility to monitor real-time Linux server performance, including CPU, Memory, Disk, and Process activity.

## Features
- **System Overview:** OS version, uptime, and load averages.
- **Resource Monitoring:** Real-time CPU, RAM, and Disk utilization.
- **Top Processes:** Identifies resource-heavy processes (CPU/Memory).
- **Security:** Tracks failed SSH login attempts.

## Prerequisites
- A Linux-based environment (or WSL/Ubuntu).
- `bash` (should be pre-installed on almost all Linux distributions).

## Installation & Setup

1. **Clone or Download:** Place `server-stats.sh` in your preferred directory.

2. **Make Executable:**
   Run the following command to give the script execution permissions:
   ```bash
   chmod +x server-stats.sh

   Run the script directly from your terminal:
   ./server-stats.sh
